# Calculator Web Application

## SkillCraft Technology - Task 02

A fully functional and responsive Calculator Web Application developed using HTML, CSS, and JavaScript as part of the SkillCraft Technology Web Development Internship.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Percentage calculation
- Decimal number support
- Clear (AC) functionality
- Delete (DEL) functionality
- Error handling
- Division-by-zero error handling
- Keyboard input support
- Equal button functionality
- Calculation history
- Clear calculation history
- History stored using browser localStorage
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling
- Local Storage
